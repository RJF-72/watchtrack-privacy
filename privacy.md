WatchTrack Privacy Policy
Last updated: October 22, 2026
For WatchTrack - TV Time Alternative & Importer Chrome Extension

Overview
WatchTrack is built for users affected by the TV Time shutdown on July 15, 2026. We respect your privacy. Your watch history is yours.

We do not collect, sell, or transmit your personal watch history to our servers. All imported data stays locally on your device using chrome.storage.local.

Single Purpose
WatchTrack has a single purpose: Allow users to import their TV Time export (CSV/JSON) and continue tracking TV shows and movies with where-to-watch information.

Permissions Justification
storage
We use storage permission to save your imported TV Time history, ratings, and watchlist locally so it persists between browser sessions. No data is sent to external servers.

host_permissions: https://api.themoviedb.org/*
We call the TMDB (The Movie Database) public API to fetch show titles, posters, episode counts, and streaming provider data when you search for a show. Only the show name you search is sent. TMDB's privacy policy: https://www.themoviedb.org/privacy-policy

We do not use this permission to track browsing, inject ads, or collect user data.

Remote Code
We do NOT use remote code. We do not load or execute any remotely hosted JavaScript. We do not use eval() or similar. We only fetch JSON data from TMDB API and parse it as data. All code is bundled locally in the extension package per Chrome Web Store policy.

Data Collection
Data Collected: None. WatchTrack does not collect personal information, browsing history, or watch history remotely.

Data Stored Locally: Your imported TV Time CSV/JSON data (show names, episode counts, ratings) is stored only in chrome.storage.local on your device.

Data Shared: Nothing is shared or sold. If you purchase Pro ($15.99/yr or $3.99/mo), payment is processed by Stripe. We do not receive your payment details.

Third-Party Services
TMDB API: For show metadata - https://www.themoviedb.org
Stripe: For Pro payments (if you upgrade) - https://stripe.com/privacy
Pro Subscription
Free version tracks up to 50 shows. Pro ($3.99/month or $15.99/year) unlocks unlimited tracking, backup, and stats. Payments are handled by Stripe via Chrome Web Store external payment link. No watch data is tied to payment.

Your Rights
You can delete all data anytime by removing the extension or clearing extension storage in chrome://extensions. You can export your data anytime.
